## Commands

```bash
# Install dependencies
make install          # or: poetry install

# Run development server (with hot reload)
poetry run uvicorn my_fastapi_project.app.asgi:get_application --factory --reload

# Run via CLI
poetry run my-fastapi-project serve --bind 0.0.0.0:8000

# Tests
make unit-test                         # pytest tests/unit
make integration-test                  # pytest tests/integration
make test                              # both
make coverage                          # tests + coverage report (≥90% required)

# Run a single test file
poetry run pytest tests/unit/app/controllers/test_ready.py

# Linting & formatting
make metrics          # flake8 (PEP8/257/pyflakes/complexity/TODOs) + black check
make mypy             # strict mypy type checking

# Build
make build            # Python package
make image            # Docker image
```

## Architecture

This project follows an MVC-like structure generated by [fastapi-mvc](https://github.com/fastapi-mvc/fastapi-mvc).

**Request flow:** `asgi.py` → `router.py` → `controllers/` → `views/`

- **`my_fastapi_project/app/asgi.py`** — App factory (`get_application()`). Registers the root router and the global custom `HTTPException` handler. Add startup/shutdown resource lifecycle here.
- **`my_fastapi_project/app/router.py`** — Mounts all controller routers under the `/api` prefix. Register new controllers here.
- **`my_fastapi_project/app/controllers/`** — Each file is a `fastapi.APIRouter`. Controllers import `settings` and return view model instances.
- **`my_fastapi_project/app/views/`** — Pydantic `BaseModel` response schemas. Each controller endpoint declares a `response_model` from here.
- **`my_fastapi_project/app/exceptions/http.py`** — Custom `HTTPException` (not FastAPI's built-in) that allows arbitrary response body shape. Use this instead of `fastapi.HTTPException` when you need full control over the error response structure.
- **`my_fastapi_project/config/application.py`** — `Pydantic BaseSettings` singleton (`settings`). All config is read from environment variables prefixed with `FASTAPI_` (e.g. `FASTAPI_DEBUG`, `FASTAPI_USE_REDIS`). Add new settings fields here.
- **`my_fastapi_project/cli/`** — Click CLI entrypoint; `serve` command wraps uvicorn (dev) / gunicorn (`my_fastapi_project/wsgi.py`) for production.

**Tests mirror the source tree:** `tests/unit/app/controllers/` tests controllers, `tests/integration/` hits the running app via `httpx`.

## Key conventions

- Line length: 88 (black default); flake8 is configured to match.
- All public symbols must have docstrings (flake8-docstrings enforces PEP 257).
- mypy runs in strict mode — all functions need type annotations.
- No open `TODO` comments allowed in committed code (flake8-todo enforces this).
- Coverage threshold is 90%; CI will fail below that.
